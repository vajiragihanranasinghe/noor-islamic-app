🚀 Installation

Step 1: Extract

Unzip the downloaded file.

Step 2: Open in Android Studio

  1. Launch Android Studio
  2. File -> Open -> select noor-islamic-app folder
  3. Wait for Gradle sync (5-10 min)

Step 3: Build

./gradlew assembleDebug

Output: app/build/outputs/apk/debug/app-debug.apk

🎨 Customization

Change App Name

Edit app/src/main/res/values/strings.xml:

<string name="app_name">Your App Name</string>

Change Colors

  • app/src/main/res/values/colors.xml (light)
  • app/src/main/res/values-night/colors.xml (dark)

Change Package Name

Android Studio: Right-click package, Refactor, Rename, Rename Package

Change Default Location

Edit HomeFragment.java - change DEFAULT_LAT, DEFAULT_LON, DEFAULT_CITY
